# 🔍 Nmap Lab — Template สำหรับส่งงาน

> วิชา: ระบบปฏิบัติการเครื่องแม่ข่าย (31901-2002) | วิทยาลัยเทคนิคอุดรธานี

## วิธีใช้
ดูคู่มือฉบับเต็มได้ที่ [network-security-lab template](https://github.com/saksit-udtc/lab-template)
(ขั้นตอนเหมือนกันทุกอย่าง แค่เปลี่ยนไฟล์คำตอบเป็น Nmap)

## สรุปย่อ
1. กด **Use this template** → สร้าง repo ส่วนตัว → เลือก **Private**
2. เพิ่ม `saksit-udtc` เป็น Collaborator
3. Clone ลงเครื่อง → ดูไฟล์ `scan_output.txt` ใน [nmap-lab](https://github.com/saksit-udtc/nmap-lab) แต่ละ lab
4. กรอกคำตอบใน `answers/labXX.yml`
5. `git add . && git commit -m "ส่งงาน" && git push`
6. ดูคะแนนที่ tab **Actions**

## หมายเหตุ
- Lab 01-04 ตรวจอัตโนมัติ
- Lab 05 (hands-on) ครูตรวจด้วยตนเอง เนื่องจากผลลัพธ์เปลี่ยนแปลงตามเวลาจริง
